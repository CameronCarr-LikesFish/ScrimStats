# Fixes for words the speech model keeps getting wrong.
# Format:   what it wrote => what it should be
#
# Matching ignores capitals, spaces and punctuation, so "kai sa", "Kaisa" and
# "KAI-SA" are all the same thing. Only whole words/phrases are replaced.
# The original wording is always kept too (as "text_raw" in the file).
#
# Spelling variants of official names (like "chogath" -> "Cho'Gath") are
# already fixed automatically; this file is for real mishearings.
# Add a line whenever you spot one. Lines starting with # are ignored.
#
# These fixes also apply to the English translations of Chinese lines, which
# is how gaming slang the translator gets wrong is fixed (我的锅 = "my bad",
# not "my pot"). Chinese fixes work too ("打也 => 打野"); for Chinese, any
# match is replaced, since Chinese doesn't put spaces between words.
