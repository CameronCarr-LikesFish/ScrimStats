# How comms get sorted into types. Open with Notepad to edit.
# Format:   Type: phrase, phrase, phrase
#
# - Matching ignores capitals and punctuation, and only matches whole words
#   ("low" matches "he's low", not "follow").
# - A longer phrase wins over a shorter one inside it ("what the fuck"
#   counts once, not also as "fuck").
# - Keep the type NAMES as they are (the dashboard relies on them).
#   Add, remove or change the PHRASES freely.
# - Lines starting with # are ignored.
