# How comms get sorted into types. Edit here in the app (Settings).
# Format:   Type: phrase, phrase, phrase
#
# - Matching ignores capitals and punctuation, and only matches whole words
#   ("low" matches "he's low", not "follow").
# - A longer phrase wins over a shorter one inside it ("what the fuck"
#   counts once, not also as "fuck").
# - Keep the type NAMES as they are (the dashboard relies on them).
#   Add, remove or change the PHRASES freely.
# - Lines starting with # are ignored.
#
# CHINESE: Chinese phrases can go on the same lines (separate them with
# commas; Chinese commas ，and 、 work too). They're matched against the
# original Chinese wording, so the stats don't depend on the translation.
# Because Chinese doesn't put spaces between words, a Chinese phrase counts
# wherever it appears in a line, so prefer phrases of 2+ characters.
# Who a Chinese line is about: 我 = yourself (but not 我们, "we"),
# 你 / 你们 = a teammate, 他 / 她 / 他们 / 对面 / a champion name = the enemy.
