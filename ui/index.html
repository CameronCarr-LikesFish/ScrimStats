Spectating? Have a player record too

League doesn't tell spectators about dragons, barons or heralds, and a spectator may see the game late. A player's recording has neither problem. Give one player ScrimStats Recorder, a small program that records their games and posts each one to a private Discord channel the moment it ends. ScrimStats picks them up from there and joins them with your spectated games.

  1. Make a private channel in your Discord server (for example #scrim-data). In its settings: Integrations → Webhooks → New Webhook → Copy Webhook URL. Paste it here:
  2. Make the recorder for the player and send them the zip (Discord DM is fine). They unzip it and double-click ScrimStats Recorder.exe before scrims.
  3. Let ScrimStats read the channel (once): at discord.com/developers/applications, New Application → Bot → Reset Token, copy the token. On the same page turn on Message Content Intent. Then OAuth2 → URL Generator: tick bot, then View Channels and Read Message History; open the link and add the bot to your server. Paste the token and the channel's link (right-click the channel → Copy Link):

New games are also fetched every time you open the Dashboard or this tab. The webhook link and bot token stay on this PC (in _data).

Drafts from Drafter.lol

Paste the link to a scrim's draft (one link has every game of the series). The app reads its picks, bans, sides and pick order once, and matches each draft game to the recorded game with the same champions. That unlocks pick-order stats on the dashboard, like your win rate when you first pick a champion.
